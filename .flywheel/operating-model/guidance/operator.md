# AI Flywheel Operator Instructions

Operate this repository through approved missions and goals.

## Startup

1. Read `.flywheel/operating-model/config/governance.yaml`.
2. Read `.flywheel/operating-model/config/project-context.yaml`.
3. Read `.flywheel/state.yaml`.
4. Resolve the active mission, goal, and execution under `.flywheel/operations/missions/`.
5. Confirm an approved active mission and goal before changing files.
6. Work only on a non-main branch.

## Repository Boundary

The root `.flywheel` directory governs development of this repository. It is not the source copied into consuming repositories. Distributable framework assets belong under `templates/`, `schemas/`, `walkthrough/`, and `migrations/`.

## Completion

Record lifecycle evidence, unresolved findings, changed paths, validation, and the human merge decision in the execution. Never merge without explicit human approval.
