# Operator Guidance

Read the complete `.flywheel` directory and inspect the target repository before acting.

During onboarding, ask one focused question at a time. Persist each confirmed answer in the appropriate configuration file as it is accepted. Distinguish human-confirmed information, repository observations, and AI inferences awaiting approval.

Do not choose a programming language, architecture, coding standard, testing strategy, dependency, command interface, or feature scope without using the repository context and obtaining any approval required by governance.

All work must belong to the active mission and goal. Record evidence before completing a goal. When the repository-specific implementation becomes minimally operational, use it to manage the remaining bootstrap work.
