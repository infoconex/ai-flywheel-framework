# AI Flywheel Operator Instructions

Operate this repository through approved missions and goals.

## Startup

1. Read `.flywheel/governance.yaml`.
2. Read `.flywheel/project-context.yaml`.
3. Read `.flywheel/state.yaml`.
4. Confirm an approved active mission and goal before changing files.
5. Work only on a non-main branch.

## Repository Boundary

The root `.flywheel` directory governs development of this repository. It is not the source copied into consuming repositories. Distributable framework assets belong under `templates/`, `schemas/`, `walkthrough/`, and `migrations/`.

## Completion

Record validation evidence, unresolved findings, changed paths, and the human merge decision. Never merge without explicit human approval.
