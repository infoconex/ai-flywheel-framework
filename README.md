# AI Flywheel Framework

The official installable implementation of the [AI Flywheel specification](https://github.com/Infoconex/ai-flywheel-spec).

> A loop repeats. A flywheel compounds.

## Purpose

This repository provides the project structure, instructions, workflows, schemas, defaults, and supporting assets used to operate an AI Flywheel inside a software repository.

The framework turns the specification into a practical, repeatable operating model for AI-assisted work. It is intended to be installed into a target repository and managed by the [AI Flywheel CLI](https://github.com/Infoconex/ai-flywheel-cli).

## Responsibilities

The framework is responsible for:

- Defining the installed Flywheel project structure
- Providing mission and goal workflows
- Providing AI instructions and standard operating procedures
- Capturing evidence, observations, findings, decisions, and lessons learned
- Supporting validation, persistence, and reuse
- Providing schemas, templates, defaults, and conventions
- Remaining aligned with the AI Flywheel specification

## Relationship to the AI Flywheel ecosystem

| Repository | Responsibility |
|---|---|
| [ai-flywheel-spec](https://github.com/Infoconex/ai-flywheel-spec) | Defines the normative specification |
| **ai-flywheel-framework** | Provides the official installable implementation |
| [ai-flywheel-cli](https://github.com/Infoconex/ai-flywheel-cli) | Installs, manages, validates, and executes Flywheel operations |
| [ai-flywheel-sample](https://github.com/Infoconex/ai-flywheel-sample) | Demonstrates the framework in a working repository |

## Status

This repository is under active development. The initial focus is defining the installable structure and establishing clear boundaries between the specification, framework, and CLI.
